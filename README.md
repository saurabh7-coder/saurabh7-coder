## Featured projects

### 🔭 [Observability & Log Analytics Platform](https://github.com/saurabh7-coder/observability-log-analytics-platform)

A production-style observability platform that ingests simulated microservice logs through Vector and Kafka, stores them in ClickHouse, detects anomalies with Python/Airflow, and visualizes service health in Grafana and Next.js.

**Stack:** Python · Kafka · Vector · ClickHouse · Airflow · Grafana · Next.js

### 🍽️ [Smart Restaurant Platform](https://github.com/saurabh7-coder/smart-restaurant)

A full-stack restaurant application with double-booking prevention, reservation scheduling, order workflows, JWT authentication, role-based dashboards, and payment handling.

**Stack:** React · Node.js · Express · MongoDB · JWT · Razorpay

### 📊 [Student Performance Data Pipeline](https://github.com/saurabh7-coder/student-performance-data-pipeline)

An end-to-end ETL pipeline that cleans, validates, transforms, loads, and reports student performance data using Pandas and SQL-based analysis.

**Stack:** Python · Pandas · NumPy · SQLAlchemy · MySQL · Pytest
